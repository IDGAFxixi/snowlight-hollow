# Snowlight Hollow

An interactive 3D winter diorama built with Three.js: a log cabin, a snowy road, pine trees and a street lamp.

Live controls: time of day, snow intensity, snowflake size, wind strength and direction, fog, and a blizzard preset.

Open `index.html` in a browser, or view it on GitHub Pages. Three.js r128 is bundled in `vendor/`, so the page has no CDN dependency.
